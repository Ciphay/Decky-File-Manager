# Decky File Manager

Decky File Manager is a file manager designed specifically for SteamOS and devices using systems based on it, providing file management directly inside Steam Gaming Mode.
The plugin is designed around a console-like experience, allowing users to browse, organize and manage their files using a game controller without needing to leave Steam or switch to Desktop Mode.

### File Management
<img width="960" height="540" alt="image" src="https://github.com/user-attachments/assets/50468f88-c707-47ac-a2e6-d70086b6c3c8" />

* Browse files and folders
* Navigate through the filesystem
* Copy files and folders
* Move files and folders
* Rename files and folders
* Delete files and folders
* Create new folders
* View file and folder properties
* Select files and folders
* File and folder context menus

### Storage
* Browse available storage devices
* Switch between different drives and storage locations
* Access internal and external storage
* Manage files across different storage devices

### Dual Panel
<img width="960" height="540" alt="image" src="https://github.com/user-attachments/assets/38bbb003-d358-44e7-8336-7e8db3e72133" />
<img width="960" height="540" alt="image" src="https://github.com/user-attachments/assets/397acbea-ee0d-49ee-aef8-3aa2932fa60a" />

The file manager provides a dual-panel interface for working with two locations at the same time.
This makes common tasks such as copying and moving files between folders or storage devices easier and faster.

### Background Operations
<img width="960" height="540" alt="image" src="https://github.com/user-attachments/assets/0a441c3d-e1f7-42ff-9526-15978e319ce3" />

File operations can run in the background, allowing the file manager to remain usable while longer operations are in progress.
Operations can be monitored through their progress information without blocking the rest of the interface.

### Text Editor
<img width="960" height="540" alt="image" src="https://github.com/user-attachments/assets/976b8413-e239-492e-80c9-f68abe0d4e5e" />

A built-in text editor allows text files to be opened and edited directly from the file manager.
This makes it possible to make quick changes to configuration files and other text-based files without leaving Steam Gaming Mode.

### Interface

The interface follows a SteamOS-inspired design focused on simplicity and usability.
It provides:

* Controller-friendly navigation
* Structured menus
* File and folder panels
* Storage navigation
* Context menus
* Improved focus management
* Layout optimized for Gaming Mode

## Controls

| Button | Action |
|---|---|
| **X** | Open folder |
| **O** | Go up one directory (hold to exit the plugin) |
| **△** | Options menu |
| **D-pad** | Navigate, and move between panels |

## Installation

Decky File Manager can be installed through Decky Loader.
For manual installation and development, you need to download the actual release and install by decky loader as zip.
